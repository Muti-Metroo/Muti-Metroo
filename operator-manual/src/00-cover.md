## About This Manual

This is the **operator manual** -- a practical guide for the people who deploy and use Muti Metroo day-to-day. It assumes one shared host running Muti Metroo and Muti Metroo Manager, and one or more workstations (typically Debian-based Linux) running Mutiauk.

For protocol details, every configuration knob, and full feature reference, consult the **user manual** (`muti-metroo-user-manual.pdf`) shipped alongside this document on every release.
